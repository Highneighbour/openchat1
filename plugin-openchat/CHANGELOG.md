# Changelog

All notable changes to the OpenChat plugin for Eliza OS will be documented in this file.

## [0.1.0] - 2025-10-17

### Added
- Initial release of @elizaos/plugin-openchat
- OpenChat bot client integration with Eliza OS
- Express server for handling OpenChat bot commands
- JWT authentication with OpenChat
- Core actions:
  - Send messages to OpenChat
  - React to messages
  - Delete messages
  - Get chat information
- Message provider for OpenChat context
- Full TypeScript support with types
- Comprehensive documentation and examples
- Example character configuration
- Integration guide
- Environment variable validation

### Features
- ✅ Bidirectional communication with OpenChat
- ✅ Full Eliza OS plugin architecture compliance
- ✅ Support for OpenChat bot commands
- ✅ Memory management for conversations
- ✅ Context-aware responses using Eliza runtime
- ✅ Extensible action system
- ✅ Provider system for context enrichment

### Documentation
- README with quick start guide
- Integration guide with step-by-step instructions
- Example character configuration
- Environment variable documentation
- Troubleshooting guide
- API documentation for actions
